South African Inter-Ethnic Marriage PredictorThis project uses machine learning to calculate the probability of a South African marrying outside their primary home language group (acting as a statistical proxy for tribe/ethnicity). It was inspired by the TikTok concept "Fun things to do with AI: The Math behind who you statistically more likely to marry in South Africa" by creator Phile-The-PinkLady.   Project OverviewThe tool processes millions of dyadic demographic records to train a Random Forest Classifier. By inputting an individual's sex, age, home language, and province, the model outputs the statistical likelihood of them entering an inter-ethnic marriage based on actual census pairing patterns.Data Source & MethodologyThis project relies on the Stats SA Census microdata (Person records).Spousal Pairing: It links individuals within the same physical dwelling by matching the "Head/acting head" to the "Husband/wife/partner" using the unique Household ID (QID).Target Variable: The model evaluates the P08_LANGUAGE of both partners. A match is classified as 0 (Same Group), and a mismatch is classified as 1 (Inter-Ethnic).Features Used: P02_SEX, P04_AGE, P08_LANGUAGE, and DERP_USUALRESPROV (Province).Algorithm: A Random Forest Classifier with balanced class weights to account for the higher statistical frequency of same-language marriages.
